# 🎓 Student Attendance Management System (C++)

A console-based C++ application built for managing student attendance using basic data structures, functions, and a simple authentication system.  
This project was developed in **Semester 1 (BS Software Engineering)** to demonstrate understanding of fundamental programming concepts, structured logic, and menu-driven applications.

---

## ✨ Features

### 👨‍🏫 Teacher Panel
- Secure login with predefined credentials  
- Add new student records  
- Update existing student information  
- Delete student records  
- Search for a specific student  
- View complete student list  
- Mark attendance for students  

### 👩‍🎓 Student Panel
- Login using student ID  
- View personal attendance  
- Check attendance percentage  
- Determine eligibility for exams (≥ 75%)
